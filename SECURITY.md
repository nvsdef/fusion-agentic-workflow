# Security

Report vulnerabilities privately through GitHub Security Advisories.

The companion permits arbitrary Python inside Fusion as the logged-in user. It is not a sandbox. Its unauthenticated TCP socket must stay on loopback; local processes may access it. Never expose or tunnel port9876. Back up CAD data and use a disposable demo document.

Setup downloads a pinned companion and locked dependencies. It writes only the project environment, local cache, generated .local configuration, and (unless skipped/staged) the per-user Autodesk add-in. It does not alter firewall rules, credentials, global identity or approval settings. Existing different add-ins require explicit replacement and retain backups. Close Fusion first.

Client registration and cloud save require appropriate consent. Autodesk drawings need a cloud DataFile: respect organizational policy. Native drawing uses preview API; inspect applicable Autodesk terms before production use. Timeout does not cancel work: never replay uncertain mutations automatically.
