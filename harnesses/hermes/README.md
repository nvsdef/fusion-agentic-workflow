# Hermes integration

Use the root SETUP.md. setup.ps1 downloads the pinned MCP and prepares local configuration. Registration uses Hermes's supported MCP consent UI/CLI; no legacy sandbox runtime or global SOUL replacement is used.

Open this clone as workspace. AGENTS.md references the stage skills directly. For native skill discovery register the two external skill directories listed in SETUP.md, preserving existing directories. Verify the loaded skill path in a fresh session. Eight tools are recommended, GUI calls serialized, client timeout360s. Model selection and credentials remain user-controlled.
