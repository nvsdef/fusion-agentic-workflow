# Governance

Community-maintained experimental workflow, not a supported Autodesk/NVIDIA/Nous product. One agent owns dependent CAD stages. Maintainers review skill/spec changes and measured evidence; do not silently loosen gates.

MCP implementation is maintained separately at nvsdef/fusion360-mcp. Product decisions belong in the workflow specification and decision register. Installation tests, mock protocol checks, and live CAD validation are distinct release criteria.
